# TTE 心超速查 · 中文版 (Transthoracic Echocardiogram Cheatsheet)

经胸超声心动图独立中文速查网页工具。涵盖标准切面、心腔定量、瓣膜疾病严重度分级、血流动力学和标准化报告模板。

## 特性

- **纯前端零外部依赖**：基于原生 HTML/CSS/JS 构建，体积小于 80KB，内联 SVG 图标与矢量解剖图，秒级加载。
- **全平台响应式与深色模式**：针对手机端、平板与电脑端全分辨率自适应，支持一键切换浅色/深色主题。
- **即时交互**：全文本搜索、分类筛选、动态高亮与连续超声参数计算。
- **最新循证参考**：收录整合 ASE 2025、ESC 2025 最新指南定量标准。
